# 괴이 — 돌아오지 않는 수학여행 전날

아발론 메타를 결합한 학원 미스터리 소셜 디덕션 게임의 UI 프로토타입입니다.
현재는 더미 데이터 기반의 클릭 가능한 목업으로, 실시간 멀티플레이어 서버는 아직 붙어 있지 않습니다.

## 배경

지방의 오래된 사립고등학교, 수학여행을 하루 앞둔 밤. 10명이 자정을 넘겨 학교에 남고,
방송실 스피커의 정체불명 안내 방송과 함께 학교 전체가 안개(결계)에 둘러싸인다.
3년 전 실종 사건에 얽힌 10명이 서로를 찾아내거나 함께 잠식된다.

## 진영 구성 (10명)

- **탐구자 6명** — 목격자/관계자
- **괴이 3명** — 방관자, 거짓유포자, 배신자(정체를 숨긴 실제 가해자)
- **경계인 1명** — 독립 진영, 실종 학생의 진짜 행방을 찾으면 승리

## 화면 구성

- **교실 (홈)** — 단체 채팅, 시스템 방송, 진행 중 이벤트 배너
- **조사실** — 도서관(3)·보건실(2)·방송실(3)·옥상(2), 선착순 입장, 방별 단서
- **원정** — 아발론식 팀 제안 → 투표 → 성공/실패 카드 → 5원정 3승 트랙
- **프로필** — 본인 역할 카드, 진영 비밀 유지(괴이끼리만 서로를 인지), 프로토타입용 시점 전환/GM 전체 공개 도구
